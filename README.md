# LikeAholic - Social Media App

> **Academic Project Note:** Developed during the Fall 2024 semester for Java Web Programming (420-N34-LA).

A full-stack social media application featuring a React frontend and a Java Spring Boot backend. Allows users to manage posts and users, navigate seamlessly via React Router, and use an interactive like/unlike system.

## Quick Start

1. Clone the repository:
   git clone https://github.com/jackybolap/likeaholic-social-app.git
   cd likeaholic-social-app

2. Backend: Ensure the Spring Boot server is running at http://localhost:8080.

3. Frontend:
   npm install
   npm start
   Open http://localhost:3000 in your browser.

## Features & Tech Stack

- CRUD Operations: Manage posts and users with automatic list updates and relationship error handling.
- Interactive Likes: Toggleable like/unlike system with dynamic counter updates.
- Frontend: React, React Router, Bootstrap, Custom CSS.
- Backend: Java, Spring Boot, Spring Data JPA, Hibernate, MySQL/H2.

- ## Troubleshooting

- Missing react-scripts: Run npm install react-scripts
- CORS / Connection Error: Verify Spring Boot is running on port 8080.
